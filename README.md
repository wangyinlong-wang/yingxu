# 映序 Yingxu Publisher

面向单人运营者的本地内容生产工作台：Vue 3 + FastAPI + SQLite。采集公开技术资讯，生成文案、分镜、配图与配音，本地合成竖屏视频，人工审核后辅助安卓手机上传发布，再记录作品数据和运营复盘。

所有服务默认只监听 `127.0.0.1`，定位为**单人、本地、可信环境**使用，不应直接暴露到公网。模型密钥通过环境变量或本机 `.env` 提供，不进入前端、数据库、日志或备份。

## 功能概览

- **选题采集**：内置 Hacker News、Hugging Face RSS，可添加自己的 RSS/Atom 或 X 账号主页来源（公开时间线或 TikHub）。
- **Production Brief（V2）**：一次受保护文本调用生成三个创意方案，对比钩子、结构、视觉路径和预计调用次数，人工选定后再生成脚本；旧内容仍可沿用直接生成流程。
- **版本化生产预设（V2）**：科技快讯、数据解释、数字人口播三个只读内置预设，约束视觉类型、节奏与质量规则。
- **多类型分镜（V2）**：图片、文字卡、数据卡、引用卡混排；后三类在本地绘制，不调用图片模型，数据/引用卡必须关联已核验事实。
- **本地成片**：FFmpeg 输出 1080×1920、30fps、H.264/AAC MP4、封面、SRT 字幕与双平台文案；旁白统一到移动端响度目标。
- **自动质量检查（V2）**：每次渲染后离线检查媒体格式、抽帧黑屏、响度、字幕时序、镜头结构与事实来源，未 PASS 不能审核通过。
- **结构化合规审核（V2）**：八项合规清单绑定内容版本与审核快照；语义合规仍以人工复核为最终门槛。
- **Android 辅助发布**：ADB/UIAutomator2 完成账号核验、上传准备与提交；成功页面和作品链接证据齐备才记录“已发布”，结果不明停在核验状态，不重复提交。
- **指标与策略（V2）**：采集或补录作品指标，复盘用累计快照；策略与实验工作台记录需求信号、对标拆解和内容实验。
- **本地 AI（Apple Silicon）**：Qwen3-TTS、Chatterbox 声音复刻、Whisper 转写、MuseTalk 照片口型视频，独立进程断网运行，默认关闭。

## 支持平台与限制

- **已实测环境**：macOS（Apple Silicon）运行服务端与本机 AI；安卓真机辅助发布。
- **已校准的平台 App 版本**：抖音 40.4.0、小红书 9.46.0。这只是有限范围内的兼容性验证，不代表与平台官方合作，也不保证对其他版本普遍有效；其他版本保留保守识别与人工接管路径，不能视为已完成真机认证。
- **CI 说明**：GitHub Actions 在 Linux 上自动运行 lint、后端测试、前端类型/单元/构建与浏览器端到端测试。CI 通过**不等于** Linux 设备发布链路或本地 AI 全链路已在 Linux 上认证。
- **本地 AI 模型**：仅 Apple Silicon 路径经过实际推理验证；需要用户显式授权安装，默认关闭。
- **Hypit**：仅做过评估，未接入，本项目不声称支持。
- 源码交付不包含 `.env`、运行数据库、私人素材和本地模型；诊断材料的脱敏要求见 [安全政策](SECURITY.md)。

## 快速开始

环境要求：Python 3.11～3.13、Node.js 22+、uv、pnpm、带 libass 字幕支持的 FFmpeg/ffprobe。本机前端在 Node.js 24 下完成验证。

```sh
git clone https://github.com/wangyinlong-wang/yingxu.git
cd yingxu
cp .env.example .env   # 仅在本机填写密钥，永远不要提交真实 .env
```

先做环境检查，再部署启动：

```sh
./scripts/deploy-local.sh --check   # 只检查环境，不安装、不迁移、不停服务
./scripts/deploy-local.sh           # 首次部署或代码更新后的一键部署
./scripts/start-local.sh            # 日常使用的一键启动（幂等）
```

`deploy-local.sh` 检测 Python、Node.js、uv、pnpm、FFmpeg/libass、ffprobe、锁文件与磁盘空间；检测失败时不会安装、迁移或停止已有服务。已有数据库会先生成可校验备份，再安装锁定依赖、构建前端、迁移数据库、重启本项目服务并验证健康接口。

`start-local.sh` 是幂等的本地启动入口：服务已经健康时直接打开工作台；检测到本项目部分进程运行或健康异常时，只重启进程签名匹配的本项目服务。两个脚本均只部署到当前电脑并监听 `127.0.0.1`，不执行远程发布。

本机入口：[打开工作台](http://127.0.0.1:8765)。

也可以在项目根目录使用控制脚本：

```sh
python3 scripts/control.py setup    # 环境检查 + 安装锁定依赖 + 构建前端 + 数据库迁移
python3 scripts/control.py start
python3 scripts/control.py status
python3 scripts/control.py doctor
python3 scripts/control.py stop
```

`start` 启动 API、内容任务进程和设备任务进程。日志位于 `data/logs/`。`restart` 只管理启动记录与进程签名都匹配的本项目进程。

## 模型凭据与付费边界

首次使用时将 `.env.example` 复制为 `.env`，仅在本地填写密钥；已有 `.env` 应保留，部署不会覆盖。工作台设置页填写服务地址、模型名和协议，启用前检查每日调用上限。

```text
PUBLISHER_TEXT_API_KEY=在本地填写
PUBLISHER_IMAGE_API_KEY=在本地填写
PUBLISHER_SPEECH_API_KEY=在本地填写
PUBLISHER_TIKHUB_API_KEY=需要X数据采集时在本地填写
```

- 文本、图片、配音三种能力分别配置；支持文本不代表支持图片或配音。
- 模型开关和自动计划默认关闭；读取或保存设置不会调用模型。
- 用量记录与账单费用分开；未取得服务商账单信息时费用显示未知，不显示 0。
- 模型请求超时或结果不明会暂停并禁止自动重发；用户核验服务商未完成后才能明确重试。

## 使用流程

1. 在“选题库”采集内置 Hacker News、Hugging Face RSS，或添加自己的 RSS/Atom、X 账号主页来源。X 可选择公开时间线或 TikHub；TikHub 每次确认后读取一页，计入每日模型/数据调用额度，不自动翻页或重试。X 仅筛选近 30 天科技、AI 相关帖子，空结果不会补造。部分候选读取失败时会显示实际采集范围。
2. 从选题创建内容，在“内容工作台”选择版本化生产预设。可先生成 Production Brief，对比三个创意方案的钩子、结构、视觉路径和预计调用次数，人工选定后再生成脚本；旧内容仍可沿用原来的直接生成流程。
3. 生成脚本、素材和视频时，可混用图片、文字卡、数据卡和引用卡。后三类卡片在本地绘制，不调用图片模型；数据和引用卡必须关联已核验事实。每个镜头可填写叙事意图、主视觉标记、黄色关键词、动画和转场。修改会产生新版本、使原审核失效；未改变画面和配音的事实核验或平台文案修改可复用视频。
4. 每次渲染后自动执行本地质量检查，覆盖媒体格式、抽帧黑屏、响度、字幕时序、镜头结构及数据/引用来源。只有当前版本、当前视频取得 `PASS`，并核验全部事实、平台文案和八项结构化合规清单后才能通过审核。开启“审核通过后自动发布”时，确认框会明确显示通过后将自动上传并发布；默认关闭该开关，保留手动准备模式。
5. 自动模式需要成功页面和作品链接证据才记录“已发布”；结果不明时停在核验状态，不重复点击。手动发布或自动结果待核验时，在绑定手机打开刚发布的作品详情，工作台可核对已审核标题并自动读取作品链接；仍保留人工填写链接作为设备不可用时的降级入口。平台短链接会经过受限的公开网络跳转解析为作品 ID。
6. 采集手机上可见的作品指标，或人工补录。不可获取的指标保持为空；零值与缺失值分开。复盘使用累计快照，不把同一作品多个时间点相加。“策略与实验”可记录需求信号、对标拆解和内容实验，并查看每条关联发布的最新指标与增量；公开链接只供人工查看，不会自动抓取。

## 模型协议

| 能力 | 协议 | Base URL 应包含的前缀 | 程序追加的路径 |
|---|---|---|---|
| 文本 | OpenAI 兼容 | 服务商提供的 `/v1` 或 `/compatible-mode/v1` | `chat/completions` |
| 图片 | OpenAI / 火山方舟 | `/v1` 或 `/api/v3` | `images/generations` |
| 配音 | OpenAI 兼容 | `/v1` | `audio/speech` |
| 配音 | 百炼原生 | 业务空间域名下的 `/api/v1` | `services/audio/tts/SpeechSynthesizer` |

三种能力分别配置；支持文本不代表支持图片或配音。Base URL 不应重复包含上述最终路径。文本的 JSON 模式、输出 Token 上限和思考开关仅在配置后发送。Seedream 使用单图、非流式输出；“图片角落 AI 生成字样”默认关闭，对应服务商 `watermark=false`。若方舟仍返回右下角平台字样，程序会用提示词预留的底部安全区相邻纹理替换最下方 8%，保持原始分辨率和 9:16 比例；平台的 AI 内容声明独立保留。百炼 `qwen-audio-3.0-tts-plus` 使用其支持的音色，例如 `longanlingxin`，不能沿用 OpenAI 的 `alloy`。

Qwen-Audio-3.0-TTS 可填写“朗读指导”，通过 `input.instruction` 传递，指导不会拼入朗读正文。其他模型不自动套用该参数；配置不兼容时在发送前报错。每个镜头整段合成，保留句间节奏；已有逐句音频仍可正常合成。同模型的云端复刻音色 ID 仍可填写在音色字段。

Apple Silicon 本机另支持 Qwen3-TTS、Chatterbox Multilingual V3 声音复刻、Whisper 参考录音转写及 MuseTalk 1.5 照片口型视频。在“模板与设置 → 本人声音与数字人”上传 3～30 秒本人录音和单人正面照片，选择模型生成试听与预览。Qwen3 需要核对录音文字；Chatterbox 仅需参考音频，并支持 0～1 的表现力强度。试听参数与后续默认设置分开保存。模型通过独立进程断网运行，配置默认关闭；已有内容可选择“用本人声音生成视频”重新合成并审核。安装、资料要求和使用限制见 [本地声音与数字人](docs/local-ai.md)。

配图生成会结合当前镜头的旁白、画面标题及最相关的一条事实，按内容模板统一视觉语言，并明确要求原生 9:16 构图、标题/字幕安全区、单一视觉焦点和相邻镜头差异。精确数字与名称交由本地标题、字幕呈现，减少图片模型错误绘字。每个镜头支持单独重绘并重新合成，保留其他图片与全部原配音；这项操作会调用图片模型，仍需检查语义是否准确。

## 视频与恢复

- 默认输出 1080×1920、30fps、H.264/AAC MP4、PNG 封面、SRT 字幕和两平台文案 ZIP。
- 默认按配音的自然时长成片，目标秒数用于规划文案，不强行拉长或压缩声音。需要严格匹配时，可选择“变速匹配目标时长”，范围为 0.5～2 倍；差距过大时要求调整文案或目标，不自动重新调用配音。
- 云端或本地旁白会在最终合成时统一到 -16 LUFS、峰值不高于 -1.5 dB 的移动端节目响度目标；只调整响度，不改变语速或音色模型参数。
- 字幕使用显式视频分辨率的 ASS 排版后烧录，关键词以黄色强调，换行后保持高亮；SRT 保留纯文本。整镜头包含多句话时，在该音频实际时长内按句子字数分配字幕时间，属于估计对齐，需在预览中检查。画面标题由本地排版，不依赖图片模型绘字。
- 已完成产物按内容与输入指纹缓存。任务恢复有租约检查；晚到结果不会覆盖已接管状态。
- 模型请求超时或结果不明会暂停，禁止自动重发。用户核验服务商未完成后才能明确重试；放弃未知请求后，相同请求指纹仍禁止重复调用。
- 取消不能撤回已经送达服务商的请求，也不能删除手机中的草稿或已发布作品。

## 安卓准备

1. 安装官方 Android Platform Tools（Android Debug Bridge 至少 1.0.41），或通过 `.env` 的 `PUBLISHER_ADB_PATH` 指定本机已有新版 ADB；此设置只影响本项目进程。不要使用微信开发者工具等应用内置的旧 ADB。
2. 通过 USB 或已配对的无线调试连接安卓手机，由用户完成调试授权和平台登录。无线 ADB 显示 `host:port` 时，程序会读取同一设备的 `ro.serialno` 作为稳定的钥匙串与失败锁身份，ADB 命令仍只发送到当前已授权传输。需要自动解锁时，按下方说明将物理序列号对应的 PIN 保存到本机钥匙串。小米/Redmi 若出现 `INJECT_EVENTS` 拒绝，还需由用户检查“USB 调试（安全设置）”。
3. 明确选定设备后初始化 UIAutomator2。必须使用子命令后的 `--serial`，避免初始化其他设备或额外输入法：

```sh
cd backend
# 先确保所选 adb 所在目录位于当前进程 PATH
uv run python -m uiautomator2 init --serial 设备序列号
```

4. 在工作台绑定平台、账号标识与设备；设备检查和上传前都要核实当前账号。自动模式会解锁、进入目标应用本人主页、准备上传并提交发布。登录、验证码和权限弹窗需要本人处理。

真机流程依赖 App 版本和可见控件。未知页面、账号不符、素材无法唯一识别时会停在“需处理”；上传准备和最终发布是两个状态。等待用户处理期间该手机保持逻辑占用，其他任务不会切走现场。

抖音 40.4.0 的相册入口按实际设备校准：每条成片与封面单独放入 `lp_文件指纹` 相册，传输后校验完整哈希，再检查媒体库记录和唯一视频条目。标题、正文分别填写并回读。自动模式在最终点击前持久化提交记录；中断或结果不明时禁止重放，只有明确核验未发布后才能取消并解除防重。小红书 9.46.0 已校准“编辑主页”“从相册选择”和“全部/视频/照片”页面；其自定义媒体网格不暴露文件名时，必须先人工核对 SHA-256、时长和预览，再通过审计接口恢复同一任务，不按缩略图位置盲点。真实提交会在“发笔记”后唯一选择“含 AI 合成内容”并点击“确认并发布”；官方 `xhslink.cn/.com` 短链校验后落库时会去除追踪参数。其他版本保留保守识别与人工接管路径，不能视为已完成真机认证。

保存手机 PIN（仅 macOS，交互输入不回显）：

```sh
cd backend
.venv/bin/python -m app.manage device-pin set --serial 设备序列号
.venv/bin/python -m app.manage device-pin status --serial 设备序列号
# 停用并删除该设备的自动解锁凭据：
.venv/bin/python -m app.manage device-pin delete --serial 设备序列号
```

PIN 存在本机钥匙串，按项目和设备隔离，不参与云同步或项目备份。后台读取需要当前 macOS 用户会话能够访问钥匙串；不可访问时停止，不退回明文文件。系统 PIN 输入失败或输入过程被中断后会禁止自动重试，重新保存 PIN 才解除。系统上锁状态、窗口包名、数字键唯一性及触控位置均会核验；未识别的锁屏方式不会尝试输入。

采集指标前请在手机停留于绑定账号的本人主页。抖音 40.4.0 使用已安装应用注册的作品入口打开视频，再复制当前作品链接比对完整作品 ID；只读取原生计数控件。页面只显示“赞”“评论”等文字时保留为空，不能将其当作零，也不会将文案中的数字当成指标。

## 备份与恢复

```sh
python3 scripts/control.py backup
python3 scripts/control.py verify-backup --from /备份目录
python3 scripts/control.py stop
python3 scripts/control.py restore --from /备份目录
# 阅读目标与影响后再明确确认恢复：
python3 scripts/control.py restore --from /备份目录 --confirm-restore
python3 scripts/control.py start
```

备份包含一致的 SQLite 快照、已登记素材与校验清单，不包含 `.env` 密钥。恢复前会另存当前数据；恢复后关闭模型和计划，未完成任务进入核验状态，防止重放旧任务。日常不自动删除业务数据或原素材。数据库升级前先备份；迁移 `0002` 的降级会丢失模板历史，迁移 `0003` 的降级会丢失 Brief、质量报告、合规明细与策略实验数据，均应优先从升级前备份恢复。

## 开发与验证

```sh
cd backend
uv run pytest
uv run ruff check app tests
cd ../frontend
pnpm typecheck
pnpm test:unit
pnpm build
pnpm dev
# 会自动启动隔离的 5173 前端服务（不发布真实内容）：

```

端到端测试需要已安装 Playwright Chromium；也可用 `PLAYWRIGHT_EXECUTABLE_PATH` 指向本机已有的测试浏览器。测试命令会按需启动并回收 5173 服务；开发前端通过代理访问 8765。接口机器文档为 [OpenAPI](http://127.0.0.1:8765/api/openapi.json)，也提供 [离线接口定义](docs/openapi.json)。

贡献前请先阅读 [贡献指南](CONTRIBUTING.md)。默认测试不执行真实付费模型调用，也不点击真实平台的最终发布。
